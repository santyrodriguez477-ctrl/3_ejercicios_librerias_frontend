# Ejercicio B — Orbit con Anime.js
Experiencia animada de presentación de producto. Usa `animate()`, `stagger()` y `createTimeline()`, además de interacción por clic.
## Ejecutar
Abre `index.html` con Live Server. Se carga Anime.js 4.0.2 desde CDN, por lo que requiere conexión a internet.
## Curvas de aceleración
- `outExpo`: entrada principal con desaceleración marcada para dar sensación fluida.
- `outCubic`: contadores que arrancan con energía y terminan suavemente.
- `outElastic`: microinteracción con rebote para indicar que el dispositivo es interactivo.
