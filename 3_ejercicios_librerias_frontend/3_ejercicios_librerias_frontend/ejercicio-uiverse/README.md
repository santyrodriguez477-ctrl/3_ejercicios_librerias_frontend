# Ejercicio A — NexaTech (Uiverse.io)
Landing page responsiva con botón, tarjetas, campos de formulario y toggle de tema. Los componentes son implementaciones propias inspiradas en patrones de Uiverse; no se copiaron piezas específicas de un autor, por eso no se atribuyen enlaces individuales.
## Ejecutar
Abre `index.html` en el navegador o usa Live Server en VS Code.
## Interacciones
- Toggle de cabecera cambia tema.
- “Me interesa” lleva el producto al formulario.
- El formulario valida campos y muestra confirmación local; no requiere backend.
