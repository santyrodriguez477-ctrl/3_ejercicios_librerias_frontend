# Ejercicio C — NexaShop Admin (React + shadcn/ui)
Panel administrativo con métricas, tabla filtrable, formulario validado, diálogo y modo claro/oscuro. El diálogo usa Radix UI, una de las primitivas sobre las que se construyen componentes de shadcn/ui; los estilos y componentes de interfaz están dentro de `src`, para poder modificarlos en el proyecto.
## Requisitos
Node.js 20 o superior y npm.
## Ejecutar
1. Abre esta carpeta en VS Code.
2. En la terminal ejecuta `npm install`.
3. Ejecuta `npm run dev` y abre la dirección local que indique Vite.
4. Para comprobar compilación: `npm run build`.
## Nota sobre shadcn/ui
La actividad pide incorporar componentes mediante la CLI. Este ejercicio incluye una implementación funcional con React, Tailwind y Radix, no componentes generados por la CLI oficial. Para completar esa evidencia en el proyecto, consulta la guía oficial Vite y ejecuta `npx shadcn@latest init` y `npx shadcn@latest add button card input label dialog`. La CLI puede adaptar archivos de configuración y generar componentes en `src/components/ui`; revisa los cambios antes de reemplazar la interfaz ya funcional.
